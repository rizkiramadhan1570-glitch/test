Portofolio Karya & Proyek

Dokumentasi hasil karya individu maupun kelompok dengan penjelasan kontribusi nyata.

Keterangan Kontribusi: Seluruh karya yang ditampilkan mencantumkan peran spesifik, jenis tugas (individu/kelompok), serta tautan/kredit sumber sesuai ketentuan akademik.
Tugas Individu

1. Visual Sitemap Website Portofolio (Draw.io)

Deskripsi: Perancangan hierarki struktur halaman website (Level 0 Beranda hingga Level 1 Kategori) menggunakan draw.io sebelum tahap coding dimulai.

Tools: app.diagrams.net (Draw.io)

Kontribusi: 100% Mandiri (Perumusan arsitektur informasi, penyusunan node tree, dan relasi link navigasi).

Tugas Individu

2. Website Portofolio Multi-Halaman

Deskripsi: Pengembangan website pribadi dengan file HTML terpisah untuk tiap halaman serta stylesheet CSS eksternal terpadu, menerapkan konsep Client-Server dan HTTPS.

Tools: HTML5, CSS3, Visual Studio Code / GitHub Pages

Kontribusi: 100% Mandiri (Penulisan kode, penyesuaian layout responsive, dan uji coba tampilan di mobile & desktop).

Proyek Kelompok

3. Media Edukasi Pembelajaran Interaktif

Deskripsi: Pembuatan modul digital materi pembelajaran sekolah dasar berbasis Canva & Google Sites dengan navigasi yang ramah anak.

Tools: Canva for Education, Google Sites

Kontribusi Pribadi: Bertindak sebagai UI/UX Designer & perancang alur navigasi menu, menyusun 4 halaman konten utama, dan menguji responsivitas tombol.

Riset & Presentasi

4. Infografis: Anatomi URL & Keamanan HTTPS

Deskripsi: Perancangan infografis edukatif mengenai perbedaan HTTP vs HTTPS, struktur protokol, subdomain, domain institusi, dan TLD nasional (.id).

Sumber Materi: Bahan Tayang P10 Dosen Rini Juliana Sipahutar

Kontribusi: Penyusunan visualisasi analogi server-hosting dan enkripsi SSL/TLS.
